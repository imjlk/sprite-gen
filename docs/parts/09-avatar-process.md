# 메이플식 파츠 조합 아바타 제작 프로세스

> Owns: 표준 포즈에 호환되는 파츠를 만들고 조합하는 전체 제작 순서, 단계별 산출물과 승인 관문, 메이플식 개념과 구현의 대응 · Index: [docs/README.md](../README.md)

목표는 **"공통 포즈 규격 + 그 규격에 맞춘 파츠를 조합하는 시스템"**과 **"그 규격에 맞는 파츠 제작을 AI로 보조하는 도구"**다.
옷 한 장을 모든 동작에 자동으로 변형하는 기술이 아니다. 정해진 포즈마다 옷·머리·장비 그림을 준비하고, 부착점·앞뒤 순서·가림 규칙으로 정확하게 다시 조합한다.
조합 시스템의 정확성과 AI의 제작 성공률은 분리해서 다룬다. 앞의 것은 규칙으로 보장하고, 뒤의 것은 파츠 단위 검수로 관리한다.

## 원칙

1. **모션은 하나, 파츠는 포즈에 대응한다.** 공통 모션이 "지금 이 포즈"를 지정하면, 모든 파츠가 그 포즈의 자기 그림을 꺼낸다. 몸체와 의상이 각각 걷기를 만들지 않는다.
2. **외형 선택과 동작 선택은 분리한다.** 걷는 중에 상의를 바꾸면 현재 포즈·시간은 그대로 두고, 상의만 같은 포즈의 다른 디자인 그림으로 교체한다.
3. **위치는 부착점, 모양은 포즈별 그림이 맡는다.** `그리는 위치 = 현재 포즈의 부착점 − 파츠 이미지 안의 부착점`이다. 굽힌 팔에 맞는 소매는 그 포즈용 그림이 해결한다.
4. **겹침은 규칙으로 정한다.** 레이어 순서표(zmap)와 가림 규칙(vslot)을 미리 정해 두고, 파츠는 그 규칙을 따른다.
5. **조합 결과는 만들지 않는다.** 슬롯 5개 × 10종이면 완성 외형 10⁵개 대신 파츠 50개와 각 파츠의 포즈 그림만 만든다.
6. **포즈 세트를 먼저 고정하고 파츠를 쌓는다.** 새 옷은 기존 포즈 규격에 맞추면 된다. 새 포즈를 추가하면 그 포즈를 지원할 모든 옷이 대응해야 한다.

## 제작 단계

각 단계는 산출물과 승인 관문을 가진다. 관문을 통과하지 않은 산출물은 다음 단계의 입력이 되지 않는다.

### 1. 체형 규격 확정 — 사람

정할 것: canvas와 방향(예: 128×128, 순수 측면 오른쪽), 몸 키(예: 89px), 슬롯 목록, 부착점 이름, 몸 조각 목록, 그리기 순서표(`layers`), 가림 태그.
SD 인간형의 최소 몸 조각은 뒷팔 / 뒷다리 / 몸통+머리 / 앞다리 / 앞팔이다. 소매와 바짓가랑이를 앞뒤로 나누려면 몸이 이 정도로는 나뉘어 있어야 한다. 몸 조각이 topology의 required node를 모두 제공해야 하므로(한 조각이 손·발처럼 여러 node를 맡을 수 있다), 조각 목록과 node 목록을 이 단계에서 맞춘다.

| 산출물 | 도구 | 관문 |
|---|---|---|
| topology(`layers` 포함)·rig·catalog | `parts-init --preset human.sd.v1` 후 편집 | `parts-validate` |

### 2. 기준 몸 원본 — AI 생성 + 사람 승인

대머리, 빈 얼굴(이목구비는 표정 파츠), 무늬 없는 속옷, 맨손·맨발의 기준 몸 한 장이다. 1단계 시점과 키로 그리고, 재질마다 3–5단계 음영과 1px 외곽선을 넣는다.

| 산출물 | 도구 | 관문 |
|---|---|---|
| native base still, 고정 팔레트 | `gen` → `still-audit --target-height N --fix` | `still-audit` 통과 + 사람 승인 |

### 3. 기준 포즈 라이브러리 — AI 영상 + 도구 + 사람 승인

**동작이 아니라 포즈를 확정하는 단계다.** 이후 모든 파츠가 이 포즈 목록을 대상으로 만들어진다.

1. 기준 몸으로 동작 영상을 만든다. 걷기·뛰기는 `video-set`, 아이들은 기준 몸에 `breathe`를 적용한다.
2. 영상 루프를 native 포즈로 옮긴다. `parts-loop-native --resample lattice`가 영상이 그린 픽셀 격자를 그대로 읽는다.
3. 같은 그림의 프레임을 하나의 포즈 ID로 묶는다(`parts-pose-assign`). 클립은 `포즈 ID + 시간`의 나열이 된다. 재생 속도 변경, 순서 재조합, 정지 프레임, 몸 전체를 몇 px 옮긴 변주는 포즈를 새로 만들지 않는다(`parts-motion-compose`).
4. 포즈마다 부착점을 잡는다. `parts-socket-track`이 제안하고 사람이 확인한다.
5. 포즈마다 몸 조각을 나눈다. 포즈 시트(`parts-pose-sheet --by-pose`)의 몸을 조각별 단색으로 칠하면(사람 또는 이미지 모델), `parts-body-segments`가 몸 raster의 픽셀만으로 조각을 자른다. 런타임에 몸을 자르거나 변형하지 않는다.

| 산출물 | 도구 | 관문 |
|---|---|---|
| 포즈 목록(포즈 ID, 부착점), 클립(포즈 참조와 시간) | `video-set`, `parts-loop-native`, `parts-motion-import --strict-motion`, `parts-pose-assign`, `parts-socket-track`, `parts-motion-freeze` | 흔들림·머리 이동 기준 통과, 부착점 승인, 포즈 세트 동결 |
| 몸 조각(segmented body pack), 포즈별 라벨 지도 | `parts-pose-sheet --by-pose`, `parts-body-segments`, `parts-import` | 조각 경계 확인(`loosely_painted` 없음), 조합 미리보기 |

이 시점에 포즈 수가 확정된다. 예: 아이들 12, 걷기 11, 뛰기 15.

### 4. 파츠 규격 정의 — 사람

슬롯마다 다음을 정한다.

- **조각 구성**: 상의는 몸통 / 앞소매 / 뒷소매, 헤어는 앞머리 / 뒷머리 / 모자용 눌린 머리.
- **레이어 위치**: 각 조각의 node. 그리기 순서표에서 그 node의 자리에 그려지고, 같은 자리에서는 몸 다음에 그려진다.
- **부착 방식**: 하나의 그림을 부착점에 다는 held, 또는 포즈마다 그림이 다른 raster(`pose_map`).
- **대응 포즈 범위**: 지원해야 하는 포즈 목록.
- **가림 규칙**: 이 파츠가 덮는 태그(`covers`)와, 다른 파츠가 덮을 때 이 파츠가 바꿔 쓰는 조각(`cover_rule`).

| 슬롯 | 조각 | 부착 | 비고 |
|---|---|---|---|
| hair | 앞머리, 뒷머리, 모자용(눌린) 앞·뒷머리 | held(머리 부착점), follow-through | `cover_rule`로 모자 유무에 따라 조각 선택 |
| expression | 눈·눈썹·입 | held(머리) | 포즈별 머리 기울기가 크면 포즈 그룹 변형 |
| headwear | 앞쪽, 뒤쪽 | held(머리) | `covers: [headwear]` |
| upper | 몸통, 앞소매, 뒷소매 | raster(포즈별) | 소매는 팔 조각 node에 놓는다 |
| lower | 허리, 앞다리, 뒷다리 | raster | |
| footwear | 앞발, 뒷발 | raster(발 확대 시트로 제작) | |
| gloves | 앞손, 뒷손 | raster | |
| back_accessory | 하나 | held(몸통), follow-through | 몸 뒤 레이어 |

### 5. 파츠 제작 — AI 보조 + 자동 검수 + 사람 승인

이 단계는 [제작 기록](10-production.md)으로 돌린다. 파츠마다 `parts-part-init`으로 시작한다. 이후 시트, 그리기, 자르기, 검사, 빌드, 검수를 반복하고, 반려한 포즈만 다시 그린다.

요청은 완성 이미지가 아니라 **파츠 단위**로 한다.

> ✗ "이 캐릭터에게 빨간 후드티를 입혀서 달리게 만들어줘."
> ✓ "이 승인된 달리기 포즈 15개에 맞춰 빨간 후드티의 몸통과 소매를 그려줘. 몸체·얼굴·손은 결과에 넣지 마."

1. **디자인 한 장**: 기준 몸(3단계 아이들 포즈)에 파츠를 그린다. 이 그림이 디자인 기준과 팔레트가 된다. 이목구비·모자처럼 held 파츠는 여기서 끝난다.
2. **포즈별 그림**: raster 파츠만 해당한다. 동결된 포즈로 포즈 단위 시트를 만들고(`parts-pose-sheet --by-pose --page-size 12 --aspect 1:1`), AI가 같은 칸 배치로 그린다. 작은 파츠(신발·장갑)는 해당 부위 확대 시트를 쓴다. 아이들처럼 기준 몸을 휘게 만든 포즈는 디자인을 같은 방식으로 휘게 해서 생성을 생략한다.
3. **추출과 조각 분리**
   - `parts-pose-slice --by-pose`: 몸 빼기 → 잔조각·번짐 정리 → 외곽선 복원 → 구멍 메우기·덮기 → 디자인 팔레트로 고정하고, 포즈별 그림(`pose_map`)으로 기록한다.
   - `parts-piece-split`: 몸 조각 라벨로 조각을 나눈다. 예: 앞팔 위 픽셀은 앞소매, 뒷팔 위 픽셀은 뒷소매, 나머지는 몸통.
4. **자동 검수**
   - 피팅: 덮어야 할 영역, 침범하면 안 되는 영역.
   - 프레임 일관성: 면적 급변, 얼룩, 빈 프레임.
   - 팔레트 준수, 포즈 커버리지(`parts-coverage`: 모든 지원 포즈에 그림이 있는지).
5. **사람 승인**: 포즈 순서대로 재생해 확인한다. 실패한 포즈는 그 포즈만 다시 생성하고, 허용 오차를 올려 통과시키지 않는다.

| 산출물 | 도구 | 관문 |
|---|---|---|
| 제작 기록(포즈별 후보: 그린 칸, 마스크, 파츠, 출처), 파츠 pack | `parts-part-init/sheet/draw/slice/mask/check/build`, `parts-review-serve` | 포즈별 검사 + 몸 위 파츠 단위 승인(`parts-part-review`, scope `part`) |

### 6. 조합과 런타임 — 도구

1. 현재 클립·시간에서 포즈를 정한다.
2. 장착 파츠마다 그 포즈의 조각 그림을 꺼낸다.
3. 부착점으로 위치를 정한다.
4. 그리기 순서표(`layers`)와 예외 규칙(`before`/`after`)으로 앞뒤를 정한다.
5. 가림 규칙(`covers`/`cover_rule`)으로 조각을 고른다.
6. 그린다.

외형 변경은 현재 포즈·시간을 유지한 채 2번만 다시 한다. 게임에서는 파츠를 직접 그려도 되고, 옷을 바꿀 때만 합성해서 캐시해도 된다. 어느 쪽이든 원본은 조합 가능한 파츠로 남는다.

| 산출물 | 도구 |
|---|---|
| 런타임 데이터(파츠 PNG, 공통 클립, 매니페스트), 미리보기 | `parts-export`, `parts-play`, 승인된 외형만 `parts-build` |

### 7. 확장 정책

| 변경 | 필요한 대응 |
|---|---|
| 새 옷 추가 | 기존 포즈 세트에 맞춘 새 파츠(5단계)만 |
| 같은 동작의 재생 속도 변경 | 시간 정보만(`parts-motion-compose`), 파츠는 `parts-rebind`로 재사용 |
| 기존 포즈를 다른 순서·위치로 조합(새 동작) | 포즈 참조·시간·offset만, 파츠는 `parts-rebind`로 재사용 |
| 팔·다리 자세가 새로운 동작 | 새 포즈 등록(3단계) + 그 포즈를 지원할 모든 파츠의 그림 추가 |
| 처음 보이는 방향(뒤통수·등) | 새 방향의 포즈·몸 조각·가림 규칙과 파츠 그림 |
| 새 체형 | 1단계부터 별도 rig. 같은 디자인은 `design_id`로 묶고 체형별 피팅 버전을 만든다 |

새 포즈를 추가하기 전에 `parts-coverage`(파츠 × 클립 × 포즈)로 영향을 받는 파츠 수를 확인한다.

## 구현 범위와 한계

- 포즈는 승인된 몸 raster 단위다. 다른 그림은 다른 포즈이고, 같은 포즈의 sample은 같은 그림을 보여 준다. 포즈를 수학적으로 변형해 새 포즈를 만들지 않는다.
- 프레임 단위 변주는 정수 이동(`offset`)과 시간뿐이다. 반전은 외형 전체(`mirror`)에만 있다.
- 몸 조각은 저작 시 고정한다. 라벨은 씨앗일 뿐이고 조각의 픽셀은 몸 raster에서만 나오므로, 조각을 합치면 원래 몸과 같다.
- 그리기 순서표는 topology 단위다. 가까운 팔다리가 바뀌는 다른 방향은 별도 topology나 mirror로 다룬다.
- 가림 규칙은 그림을 고를 뿐 픽셀을 자르지 않는다. 일부를 잘라야 하면 mask를 쓴다.
- portable 레이어 export는 몸 하나(flat 또는 segmented), 슬롯당 선택 하나, 그리기 순서표와 가림 규칙을 지원한다. 몸 교체, 슬롯 우선순위, 다중 선택은 Python 런타임에만 있다.
