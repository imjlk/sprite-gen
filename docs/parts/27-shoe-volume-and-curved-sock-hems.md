# 신발 입체감과 양말 윗선 교정 — 2026-10-12

이번 작업은 걷기에서 신발이 납작해 보이고 양말 상단이 각지는 문제에 대한 후속 교정이다. 작업본은 `assets/parts-volume-cuff-20261012/production-r1/library/assembly.json`이다. 기존 걷기 27·뛰기 23프레임과 손 피부색, walk.12·walk.26 종아리 소유 교정을 보존한다. 코디별 영상을 생성하지 않고 공통 모션 위에 독립 파츠를 렌더링한다.

신발의 이전 마스터를 편집한 첫 후보는 긴 옆면과 큰 끈이 남아 채택하지 않았다. built-in imagegen으로 [새 원본](assets/volume-cuff-20261012/shoe-volume-native.png)을 생성했다. [프롬프트](assets/volume-cuff-20261012/shoe-prompt.txt)는 짧고 둥근 앞코, 도톰한 발등, 밑창의 곡면과 얕은 상면을 요구한다. [등록 기준](assets/volume-cuff-20261012/shoe-volume-native.registration.json)은 실제 원본 SHA·크기와 수평 부착 기준선에 묶인다. 균일 확대·회전·이동만 사용한다. 이 그림은 측면 모션의 입체감을 표현하는 일러스트이며 임의 방향을 복원하는 3D 자산은 아니다.

둥근 밑창은 실제 윤곽이 곡선이므로 종전의 직선 밑창 검사에서 제외했다. 파츠 등록·가시성·몸과의 연결 검사는 유지한다. 직선을 만족시키려고 새 그림을 평평하게 누르지 않는다.

양말은 원본의 해당 다리·발 알파 안에서 프로그램으로 제작한다. 상단을 실제 종아리 중심과 폭에 맞춘 곡선으로 자르고 반투명 가장자리, 천의 명암, 얇은 접힌 선을 그린다. 발목 기준점이 종아리 중심과 다를 수 있으므로 상단의 실제 단면에서 중심을 읽는다. 신발의 UV 영역은 발·발목 연결에만 적용하고 양말 상단을 자르는 데 사용하지 않는다. 첫 교정 후보의 뾰족한 선도 이력에 보존한다. 이 코드는 현재 소스에 대한 제작 도구이며 다른 체형의 자동 포즈 추정기는 아니다.

첫 착용 렌더에는 [칼라의 흰 사각형](assets/volume-cuff-20261012/walk00-first-render.png)이 있었다. 종전 신발의 직사각형 마스크를 새 신발에 재사용한 오류였다. 전체 증거 생성은 중단하고 [미채택 기록](assets/volume-cuff-20261012/rejected-rectangular-mask.json)을 남겼다. `parts_motion_shoe_opening.py`는 [원본 입구 관찰](assets/volume-cuff-20261012/observed-shoe-opening.png), [원본 SHA에 묶인 폴리곤](assets/volume-cuff-20261012/shoe-opening-native.annotation.json)을 같은 등록 행렬로 이동한다. 해당 다리·발이 실제 입구 안으로 들어가는 영역만 비우고 앞쪽 칼라와 신발 옆면은 남긴다. 신발 PNG는 바꾸지 않으며 변경한 마스크로 새 후보·파츠 빌드를 만들고 기존 승인도 복사하지 않는다.

이전 작업본과 원본을 덮어쓰지 않는다. 수치 검사와 이미지 관찰, 실제 재생 관찰을 구분하며 아트를 자동 승인하지 않는다.

프레임별 마스크가 많아지면서 기존 `AssetLoader`의 누적 디코드 픽셀 합이 한도를 넘어 portable export가 실패했다. 뷰어가 서버 재생으로 대체되는 상태도 실제로 확인했다. 디코드 이미지 캐시를 LRU로 바꿔 상주 픽셀을 기존 한도 안에 유지한다. 한 이미지의 한도, 입력 바이트·파일 수 한도, 프레임·렌더 출력 한도는 유지한다. 퇴거 후 다시 읽는 이미지는 검증된 원본 바이트 스냅샷에서 재디코드한다. 재디코드 픽셀 동일성·캐시 복사 격리·단일 이미지 초과 거부를 포함한 관련 검사 34개를 통과했다.

[첫 전 모션 비전 관찰](assets/volume-cuff-20261012/vision-before-final-cuffs/summary.json)은 50/50프레임을 실제로 관찰했다. 신발 자체의 두께와 제품 형태는 대부분 유지됐지만 run.10, walk.12·22·23·25·26에서 양말·발목 연결 재작업 또는 가림에 따른 불확실성을 남겼다. 이 보고서를 최종 승인으로 사용하지 않는다. [run.10 원본 비교](assets/volume-cuff-20261012/run10-calf-check.png)에서 실제 원본 종아리의 98픽셀이 빠진 것을 확인했다. 종아리 일부가 교체되는 발 노드에 있고 UV 앞쪽 경계 밖이어서 소실된 것이다. 양말의 종아리 띠는 원본 leg/foot 알파의 합에서 별도로 만든다. 신발 밑창 아래로 새지 않도록 제한하면서 연결을 발목 아래 8px까지 연장한다. walk.12 앞쪽·walk.25 뒤쪽의 보이는 윗선은 별도 프레임 교정 이력에 따라 낮췄다.

걷기 25·26번은 [원본과 레이어 소유 지도](assets/volume-cuff-20261012/foreground-calf-ownership.png)에서 앞 종아리의 일부가 뒤 다리·발로 잘못 배정된 것을 확인했다. [좌표와 원본 SHA를 고정한 주석](assets/volume-cuff-20261012/foreground-calves.annotation.json)에 따라 walk.25의 1,457픽셀, walk.26의 673픽셀을 `leg_front`로 옮겼다. [이동 기록](assets/volume-cuff-20261012/foreground-calves-result.json)과 [원본 보존](assets/volume-cuff-20261012/body-preservation-final.json)을 남겼다. 몸 그림은 RGBA 그대로이며 이전 walk.12·26 보호 영역도 유지한다. 새 앞종아리는 독립 보호 검사에 추가된다. 뒤 양말을 다시 제작하면 앞 종아리에 잘못 칠해진 흰 조각이 제거되고, 뒤 발 교체 때문에 생긴 종아리 구멍도 몸 레이어 자체에서 복구된다.
